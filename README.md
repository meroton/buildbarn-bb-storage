# Prebuilt bb-storage images with patches

This repository contains bb-storage images with patches to various
things in buildbarn. This is intended to allow easy consumption of
images with patches which may not really be ready to merge. Each
individual release is tagged with the commit and date, however the
repository does not contain a linear history so consumers must review
each release independently to determine if the set of patches is
suitable for their use case.

**WARNING**: This repository is not intended to be used for long term
traceability. It is intended to be used for short term testing and
verification of patches.
